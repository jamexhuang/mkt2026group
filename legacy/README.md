# legacy/

This directory contains archived code that is no longer part of the active analysis pipeline. Do not modify or run these files.

---

## Contents

### `notebooks/`
**`Final_report.ipynb`** — Original Google Colab notebook. This was the starting point of the entire project: it scraped and cleaned the data, ran NLP feature extraction (sincerity lexicon, valence scoring, surface features), and exported the processed dataset. Archived after the NLP pipeline output was committed to `data/research_data.csv` and the analysis was moved to standalone scripts.

---

### `scripts/`
Python exports of the Colab notebook, created during a code-quality refactoring exercise. The underlying data (`data/research_data.csv`) was already finalised before these scripts were completed, so they are not part of the active pipeline.

- **`single/final_report_full.py`** — Monolithic export of the entire notebook as one script.
- **`modular/`** — Clean refactoring of the notebook split into six modules:
  - `main.py` — orchestrator / entry point
  - `preprocess.py` — text cleaning, surface feature extraction (URLs, hashtags, etc.)
  - `tokenize_stem.py` — tokenisation, stemming, n-gram generation
  - `dictionary_count.py` — count-based sincerity dictionary matching
  - `dictionary_score.py` — score-based valence / extremity / emotionality matching
  - `export.py` — Excel export helper
